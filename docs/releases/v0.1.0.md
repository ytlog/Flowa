# 随心记 Android 0.1.0

首个 Android 正式发布版本，支持 Android 8.0 及以上。

- 打开即写，自动唤起键盘，草稿自动保存，支持清除与恢复。
- 标签、全文搜索、筛选、批量整理、统计日历与随机回顾。
- 内置保存记录、整理口述、润色文案三个工作流，支持自定义步骤。
- 可连接自己的 AI 服务，使用流式 AI 助手、历史对话、记忆和技能。
- Markdown / ZIP 导入导出，支持与 iOS 版交换记录和配置。
- 专注模式、浅色与深色、独立演示数据。
- 记录和草稿保存在本机，AI 密钥加密保存。

下载 `flowa-v0.1.0.apk` 安装，`SHA256SUMS.txt` 用于校验文件。`.aab` 为应用分发产物，不能直接安装。

Android 版目前不支持 iCloud 自动同步。普通记录无需 AI 配置；AI 功能需自行配置服务、模型和密钥，相关文字会发送至该服务。

若此前安装的是 Debug 调试版，其签名与正式版不同，无法直接覆盖安装；请先导出并妥善保存记录与配置备份。
