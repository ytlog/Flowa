## 发现并修复

- Compose 1.6 与 Lifecycle 2.8 的生命周期提供器不兼容，首次真实启动暴露异常。依赖已统一到 Lifecycle 2.7，随后首页启动和设备 UI 测试通过。
- 原项目使用 `yyyy-MM-dd-HHmm-ss`，已按该格式处理日期与导出文件名。
- 草稿异步写入可能把旧文本回写到正在输入的编辑器；编辑器保持本地输入状态，仅在清除/恢复/运行结束时同步重置。
- 导出、清除和工作流执行先等待待写入队列，避免刚输入的文本被旧快照覆盖。
- ZIP 对所有条目限制展开大小和条目数，不向文件系统释放任意 ZIP 路径。
- 取消设备授权请求使用不可取消的清理区，避免挂起队列。
- 更改 AI 服务地址或密钥取消旧模型请求，保留自定义模型。
- 补充 Android 12+ 数据迁移排除规则，并在提醒通知投递时重新检查通知权限。

- 保存中文记录和标签、清空已保存草稿、Activity 重建后读取记录。
- 草稿清除、恢复、Activity 重建后的保留。
